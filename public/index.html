FIREBASE SETUP

Connect Firebase cloud syncing

The app is ready for Firebase. Add your Firebase web configuration to activate login and cloud sync.

  1. Create or open your Firebase project.
  2. Create a Cloud Firestore database, then publish the included firestore.rules.
  3. Open firebase-config.js in the public folder.
  4. Paste the Firebase configuration object from your registered Web app.
  5. Deploy with Firebase Hosting or upload the public folder to any HTTPS website.
Your Firebase web config identifies the project; access to private data is controlled by Authentication and Firestore Security Rules.
